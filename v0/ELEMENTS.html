01 设计理念

📖 文学的温度

Newsreader 衬线体 × 暖白纸色背景，让每篇文章都像一本精心排版的杂志。阅读体验温暖、沉浸。

💻 代码的理性

JetBrains Mono × 深色代码块，在浅色正文中自然区分。所有 Markdown 渲染后的 <pre><code> 结构完美兼容。

🎨 oklch 色域

基于感知均匀的 oklch 色彩空间推导，相同 Lightness 值在视觉上感知亮度一致。告别 HSL 的视觉不均。

javascript
// A recursive Fibonacci with memoization
function fibonacci(n, memo = {}) {
  if (n <= 1) return n;
  if (memo[n]) return memo[n];

  memo[n] = fibonacci(n - 1, memo) + fibonacci(n - 2, memo);
  return memo[n];
}

// The beauty of recursion meets
// the efficiency of dynamic programming
console.log(fibonacci(50)); // 12586269025

Details / Summary (折叠)

点击展开：关于 oklch 色彩空间

oklch 是 CSS Color Level 4 中引入的感知均匀色彩空间。与 HSL 不同，oklch 中相同 Lightness 值的颜色在人眼中感知亮度是一致的。这意味着设计师可以更精确地控制视觉层级——一个 0.6 亮度的黄色和一个 0.6 亮度的蓝色，看起来确实是同等亮度的。

"一本会写代码的杂志"——在有温度的纸质感中阅读文学，在理性的深色背景中阅读代码。两种气质在一本"杂志"里和谐共存。
